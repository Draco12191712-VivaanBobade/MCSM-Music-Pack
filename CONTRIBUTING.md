# Contributing

Contributions of all kinds are welcome, including:

- Bug fixes
- New features
- Documentation improvements
- Performance optimizations
- Tests
- Ideas and suggestions

Please take a moment to read these guidelines before contributing.

---

## Code of Conduct

See CODE_OF_CONDUCT.md and also no **politics**.

---

## Before You Start

Before working on a major feature or significant change:

1. Check existing Issues to see if someone is already working on it.
2. Open a new Issue if one doesn't already exist.
3. Wait for discussion if the change is large.

This helps avoid duplicate work.

---

## Reporting Bugs

When reporting a bug, please include:

- Operating system
- Minecraft version
- Add-on version
- Steps to reproduce
- Expected behavior
- Actual behavior
- Screenshots or logs (like Minecraft's built in Content Log)

The more information you provide, the easier it is to reproduce and fix the issue.

---

## Suggesting Features

Feature requests are always welcome.

Please explain:

- The problem you're trying to solve
- Your proposed solution
- Possible alternatives you've considered
- Any additional context or examples

---

## Development Setup

Follow the project's setup instructions in the README.

If setup instructions are missing, feel free to open an issue requesting them.

---

## Coding Guidelines

Please try to:

- Write clean & readable code.
- Keep functions focused and maintainable.
- Follow the existing code style.
- Use meaningful variable and function names.
- Remove unused code before submitting.
- No spamming comments
- **NO AI GENERATED CODE**
- No **politics**

---

## Commit Messages

Use clear and descriptive commit messages.

Avoid messages like:

```text
fix

stuff

update

changes

politics
```

---

## PRs

Before opening a PR, please make sure:

- [x] The project builds successfully.
- [x] Tests pass (if applicable).
- [x] New code follows the project's style.
- [x] Documentation has been updated if necessary.
- [x] The PR has a clear description.
- [x] Related Issues are referenced when appropriate.
- [x] You don't include **politics**

Small, focused PR is preferred over very large ones.
